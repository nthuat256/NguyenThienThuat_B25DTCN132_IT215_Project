# FastAPI Club Management

API quản lý câu lạc bộ được xây dựng bằng FastAPI, SQLAlchemy, MySQL và JWT Authentication.

## Công nghệ sử dụng

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- MySQL
- PyMySQL
- Pydantic
- Bcrypt
- PyJWT
- Python Dotenv
